# Sonic Arts Arcade

Interactive educational games and studio training tools for students of the Sonic Arts Center.

## Current Games

### 🎮 Patch Trainer
Practice professional studio signal flow, patchbay routing, console workflows, and DAW input assignment through interactive recording scenarios.
